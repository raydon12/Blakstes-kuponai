# Blakstės studija — dovanų kuponai

Сайт подарочных сертификатов: продажа онлайн, QR на каждом купоне, админка мастера со сканером и списаниями.

## Как устроено

- **Сайт** — один файл `public/index.html` (+ `public/vendor/`). Хостинг: Vercel, без сборки (`vercel.json`, папка `public`).
- **База** — отдельный проект Supabase «Blakstes kuponai» (`hermojruniqfvxksunrj`), не связан с NeeDo. Закрытая схема `kuponai` (таблицы `vouchers`, `staff`, `sessions`, `login_fails`).
  Сайт обращается к ней только через функции `kp_*` (файл `supabase/schema.sql`), поэтому все правила (минимум 40 €, нельзя списать больше остатка, только мастер видит купоны) проверяются в базе.
- Публичный ключ Supabase лежит в `index.html` (`#supa-config`). Это publishable-ключ, он предназначен для браузера.

## Мастера (вход в админку)

Админка: `https://<сайт>/#admin` или `/admin`. Вход по email и паролю (своя таблица `kuponai.staff`, пароль хранится только как bcrypt-хеш; 5 неверных попыток — блок на 10 минут; сессия 30 дней).

Добавить мастера (Supabase → SQL Editor):
```sql
insert into kuponai.staff(name, email, pw_hash)
values ('Имя', 'email@example.com', extensions.crypt('ПАРОЛЬ', extensions.gen_salt('bf')));
```
Сменить пароль:
```sql
update kuponai.staff set pw_hash = extensions.crypt('НОВЫЙ', extensions.gen_salt('bf')) where email = 'email@example.com';
```

## Оплата

Настоящей онлайн-оплаты пока нет. Онлайн-заказ создаёт купон со статусом «Laukia apmokėjimo» (ждёт оплаты): по нему нельзя списывать.
Когда клиент заплатил (перевод, наличные), мастер открывает купон и нажимает «Pažymėti apmokėtu». Купоны, проданные на кассе через «+ Naujas kuponas», сразу оплачены.
Когда купон оплачен, письма уходят сами (см. ниже).

## Письма

Функция Supabase `mailer` (`supabase/functions/mailer`) и SQL `supabase/mail.sql`:

- **Покупателю**: купон PDF с QR, как только купон оплачен (онлайн-заказ после «Pažymėti apmokėtu», продажа на кассе сразу, если указан email).
- **Получателю**: в выбранный день доставки с 9:00 по Вильнюсу. Покупатель сразу получает копию.
- **Салону** (`NOTIFY_EMAIL`): о каждом новом онлайн-заказе, со ссылкой на купон в админке.
- **Напоминание** за 30 дней до конца срока, если на купоне есть остаток (только для купонов старше 45 дней).

База сама вызывает функцию: триггер на таблице купонов и pg_cron каждые 15 минут. Состояние писем хранится в `doc.mail`, в карточке купона в админке видно, что ушло, и есть кнопка «Siųsti dar kartą».
Пока не задан почтовый провайдер, функция ничего не отправляет и письма ждут.

Настройка (один раз):
1. Применить `supabase/mail.sql`.
2. Секрет `mailer_key`: `select vault.create_secret('<случайная строка>', 'mailer_key');` и та же строка как секрет функции `MAILER_KEY`.
3. Задеплоить функцию `mailer` с выключенной проверкой JWT.
4. Секреты функции: `NOTIFY_EMAIL` и один провайдер: Gmail (`SMTP_USER`, `SMTP_PASS` = пароль приложения Google), Brevo (`BREVO_API_KEY`, `MAIL_FROM`) или Resend (`RESEND_API_KEY`, `MAIL_FROM`). Необязательно: `SALON_CONTACT` (телефон/адрес в подвале письма).

Шрифты PDF лежат в `supabase/functions/mailer/fonts.ts`, пересобрать: `python3 scripts/pdf-fonts.py`.

## Автоотмена, бэкап, мастера (`supabase/extras.sql`, после `mail.sql`)

- Неоплаченный онлайн-заказ аннулируется через 7 дней (pg_cron, каждую ночь). В журнале купона: «auto_cancel».
- По понедельникам `mailer` отправляет на `BACKUP_EMAIL` (или `NOTIFY_EMAIL`) все купоны: CSV для Excel и полный JSON.
- В админке кнопка «Nustatymai»: смена своего пароля (другие устройства разлогиниваются), список мастеров, добавить или удалить мастера. SQL для этого больше не нужен.

## Фото работ и отзывы

Блок «Darbai ir atsiliepimai» на главной берёт данные из `<script id="works-data">` в `public/index.html`. Фото кладите в `public/works/` (JPG/WebP ~1200 px). Пока списки пустые, блок скрыт.

## Правила и конфиденциальность

`public/taisykles.html` и `public/privatumas.html` (LT). Ссылки в подвале и в окне оформления. Реквизиты продавца отмечены жёлтыми заглушками `[…]`, их нужно заполнить.

## Возможности

Магазин: выбор суммы через кнопку «Išsirinkti kuponą» (40–1000 €), поводы с готовым текстом, 4 дизайна, доставка себе или получателю в выбранный день, PNG и печать, проверка остатка по коду, FAQ, LT/RU.

Админка: статистика за период (30 дней / месяц / год / всё: продано, сумма онлайн и в салоне, использовано, средний чек, остаток, ждут оплаты, истекают за 30 дней, сгорело), график продаж за 30 дней, лента списаний, поиск, фильтры (в т.ч. «Neapmokėti»), сортировка, CSV, продажа на кассе, QR-сканер (камера или фото). В карточке: подтверждение оплаты, списание, отмена списания, +3 месяца, аннулирование/восстановление, PNG, правка данных. Все изменения пишутся в журнал купона.

## Прайс

Услуги задаются в `public/index.html` в блоке `<script id="menu-data">` (формат: `categories[].services[]` с полями `id, name, price, priceFrom, durationMin, description, bookingUrl`). Кнопка «Registruotis» ведёт на Treatwell.

## Локальный запуск без Supabase

`node server.js` (старый вариант с JSON-файлами в `data/`), открыть http://localhost:8080. Мастер: `node scripts/add-master.js <имя> <пароль>`.
