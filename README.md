# Шаблон: сайт подарочных купонов для барбершопа

Ветка `barber`: барбершоп-версия общего шаблона (`template`) — блок «Komanda» с барберами и их портфолио, палитра чёрный + латунь, мужские тексты и прайс-пример.

Сделан из проекта Grin Lashes (`main` этого репозитория). Магазин купонов с QR, оплата/подтверждение, письма с PDF, админка со сканером, списаниями, прайсом и галереей. Языки LT/RU.

**Всё, что отличает одного клиента от другого, лежит в одном файле — `salon.config.json`.** Код трогать не нужно.

## Как устроено

```
salon.config.json      ← настройки клиента (название, цвета, суммы, ссылки, реквизиты, Supabase)
public/                ← шаблон сайта с метками {{…}}
supabase/              ← шаблон SQL и функций с метками {{…}}
scripts/build.js       ← подставляет настройки → dist/ (сайт) и build/supabase/ (для базы)
scripts/make-icons.py  ← рисует og.png и иконки из названия и цвета
```

Vercel сам запускает `node scripts/build.js` и публикует `dist/` (см. `vercel.json`). Папки `dist/` и `build/` в git не хранятся.
Если в настройках опечатка (неизвестный ключ, цвет не вида `#aabbcc`, суммы вне min–max), сборка остановится и скажет, что не так.

Без Supabase (`supabase.url` пустой) сайт работает в демо-режиме: купоны хранятся только в браузере. Удобно показать клиенту до подключения базы.

## Новый клиент — по шагам

1. **Копия шаблона.** На GitHub: «Use this template» → новый репозиторий (например `nagu-namai-kuponai`). Или попросить Claude: «сделай нового клиента из шаблона».
2. **Настройки.** Заполнить `salon.config.json`:
   - `brand` — название и подпись под логотипом (LT/RU);
   - `site.url` — адрес сайта (сначала `https://<проект>.vercel.app`, потом можно свой домен), `site.description` — текст для Google и превью ссылки;
   - `contacts.address`, `contacts.instagram` (без @, пусто — иконка скрыта);
   - `booking` — ссылка на запись и как её назвать (Treatwell, Booksy, свой сайт…);
   - `vouchers` — минимум/максимум, готовые суммы, срок действия в месяцах;
   - `colors` — главный цвет и текст на нём;
   - `texts` — любые тексты сайта поверх стандартных (ключи — из `I18N` в `public/index.html`), например `heroIt`, `marquee`;
   - `menu` — стартовый прайс (потом салон правит сам в админке);
   - `team.barbers` — стартовый список барберов (имя, специализация LT/RU, о себе, Instagram, личная ссылка на запись). Фото и портфолио загружаются в админке → «Komanda»;
   - `seller` — реквизиты для правил и политики (пустые поля видны как жёлтые `[ЗАГЛУШКИ]`).
3. **Картинки.** `python3 scripts/make-icons.py` → новые `og.png` и иконки в `public/`. Закоммитить.
4. **Vercel.** New Project → выбрать репозиторий → Deploy (настройки сборки уже в `vercel.json`). Готов демо-сайт.
5. **Supabase** (когда клиент готов к настоящим заказам):
   1. Новый проект Supabase, регион EU. Вписать в конфиг `supabase.url` и `supabase.key` (Settings → API → publishable key).
   2. `node scripts/build.js`, затем в SQL Editor по очереди: `build/supabase/schema.sql`, `content.sql` (прайс, галерея и команда), `mail.sql`, `extras.sql` (и `payments.sql`, если нужна Stripe).
   3. Задеплоить функцию `build/supabase/functions/mailer` (JWT-проверка выключена). Секреты: `NOTIFY_EMAIL` и один почтовый провайдер — Gmail (`SMTP_USER`, `SMTP_PASS` = пароль приложения), Brevo (`BREVO_API_KEY`, `MAIL_FROM`) или Resend (`RESEND_API_KEY`, `MAIL_FROM`).
   4. Первый мастер (SQL Editor):
      ```sql
      insert into kuponai.staff(name, email, pw_hash)
      values ('Имя', 'email@example.com', extensions.crypt('ПАРОЛЬ', extensions.gen_salt('bf')));
      ```
      Остальных мастер добавит сам: админка → «Nustatymai».
   5. Закоммитить конфиг — Vercel пересоберёт сайт уже с базой.
6. **Проверка.** Открыть сайт с телефона, купить купон, войти в `/admin`, отметить оплату, списать часть суммы, проверить письмо.

## Что умеет сайт (одинаково у всех клиентов)

- **Команда**: карточки барберов на главной (фото, специализация, о себе, Instagram, личная запись), портфолио каждого на весь экран. В админке «Komanda»: добавить/удалить/переставить барбера, загрузить фото и работы. Пустой список — блок скрыт.
- **Магазин**: суммы из конфига + своя сумма, услуги из прайса, поводы с готовым текстом, 4 дизайна купона, доставка себе или получателю в выбранный день, PNG и печать, проверка остатка по коду, FAQ, LT/RU.
- **Админка** (`/admin`): статистика, график продаж, лента списаний, поиск и фильтры, CSV, продажа на кассе, QR-сканер, подтверждение оплаты, списание и отмена, продление, аннулирование, журнал по каждому купону, прайс («Kainos»), галерея фото («Galerija»), мастера и пароль («Nustatymai»).
- **Письма** (функция `mailer`): покупателю PDF с QR после оплаты, получателю в выбранный день с 9:00, салону о новом заказе, напоминание за 30 дней до конца срока, бэкап всех купонов по понедельникам.
- **Безопасность**: все правила (минимум, остаток, доступ мастеров) проверяются в базе в функциях `kp_*`; пароли — bcrypt; 5 неверных попыток — блок на 10 минут.
- **Оплата**: по умолчанию заказ «ждёт оплаты», мастер подтверждает вручную. Карта через Stripe — `payments.sql` + функции `checkout` и `stripe-webhook`.

## Локально

`npm run preview` → http://localhost:8080 (сборка + простой сервер). Другой конфиг: `node scripts/build.js путь/к/конфигу.json`.
