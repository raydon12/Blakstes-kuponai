# Шаблон купонов — заметки для Claude

Артур работает с телефона. Делай всё сам, присылай ссылки, не проси запускать команды.

- Данные клиента — только в `salon.config.json`. Код в `public/` и `supabase/` общий для всех клиентов; меняй его, только если улучшение нужно всем.
- Метки `{{ключ}}` / `{{ключ|фильтр}}` подставляет `scripts/build.js` (фильтры: html по умолчанию, js, json, url, sql, raw, ph). Новый ключ — добавь в конфиг или в `data` в build.js.
- После любой правки: `node scripts/build.js` должен пройти без ошибок; проверь `dist/index.html` в headless Chrome (`/usr/bin/google-chrome`, playwright) на ширине 390 px.
- Не коммить `dist/` и `build/` (они в .gitignore).

## «Сделай нового клиента»

1. Спроси (одним сообщением, если не сказано): название, подпись, адрес, ссылка на запись, Instagram, цвет, суммы и срок, реквизиты продавца. Чего нет — оставь пример/пусто.
2. Новый репозиторий из этого шаблона (или ветка, если репозиторий создать нельзя) → заполни `salon.config.json` → `python3 scripts/make-icons.py` → сборка и проверка → commit/push.
3. Supabase и Vercel — по README («Новый клиент», шаги 4–5). SQL бери из `build/supabase/`, не из `supabase/`.
